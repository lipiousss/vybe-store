# VYBE Store

VYBE Store — дипломный проект интернет-магазина дизайнерской продукции в стилистике dark fantasy.

## Stack

- React + Vite + JavaScript
- Node.js + Express
- PostgreSQL + Prisma
- Docker + Docker Compose
- Zustand
- Framer Motion
- pgAdmin

## Main Features

- Product catalog
- Collectibles section
- Artworks visual archive
- User profile
- Favorites
- Cart
- Orders
- Admin panel
- File uploads
- Stock management
- Excel export
